# Repository Guidance

## Project
- This repository is a task manager project with planned AI features.
- `backend/app.js` is the backend entry point; it currently contains only a note about an Express task API with GET and POST endpoints.
- No package manifest, tests, or other application code is present yet.

## Working In This Repository
- Confirm the intended routes, request/response shapes, persistence model, and AI behavior before implementing them; they are not defined in the current code.
- Keep backend changes focused in `backend/` and update the README when setup or usage becomes available.
- Check the repository for available scripts and tests before choosing validation commands. Do not assume dependencies or scripts exist.
